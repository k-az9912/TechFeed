# 仕様

## ニュース

| 項目 | 動作 |
| --- | --- |
| 取得 | 起動時・手動更新時に有効なフィードを並列取得 |
| 形式 | RSS 1.0／2.0、Atom |
| 件数 | 通常は各最大100件、Qiita・Zenn は各最大30件 |
| 順序 | 通常記事は日時順、その後に Qiita・Zenn のトレンド配信順 |
| 表示 | タイトル・概要・公開日時・取得元。元記事はブラウザーで開く |
| 日時 | 端末のタイムゾーンで yyyy/MM/dd HH:mm。日付のみは yyyy/MM/dd、解析不可は「日時不明」 |
| 絞り込み | 取得元と話題タグの AND 条件 |
| 取得失敗 | 成功した取得元を表示（0件なら空一覧）。全失敗時のみメモリ上の前回一覧を維持 |

標準配信元は Android Developers、Qiita、Zenn、IPA お知らせ、IPA セキュリティ。配信 URL・言語・上限の定義：`core/feed/FeedSources.kt`。

標準の話題タグ：セキュリティ、AI、Android、Web、モバイル、クラウド・インフラ、バックエンド・API、データベース、開発ツール、プログラミング、ITニュース、お知らせ。配信元カテゴリと、タイトル・概要のキーワードから複数タグを判定する。

## 保存・設定

- 保存対象：タイトル・概要・日時・URL 等の記事情報。Room で端末内に永続化。
- 設定対象：取得元の有効／無効、カスタム配信元、カスタムタグ、タグの表示／非表示、表示順。DataStore で永続化。
- カスタム配信元：HTTPSのRSS／AtomフィードURLを入力し、取得・形式確認後にフィードタイトルを配信元名として登録。削除しても保存済み記事は残す。
- カスタムタグ：タグ名と1つ以上の判定キーワードを登録。キーワードはカンマ・読点・改行区切りで、大文字小文字を区別せずタイトルと概要へ照合する。削除しても記事や配信元は残す。
- 取得元の変更時：進行中の取得をキャンセルして再取得。全無効時は取得停止。
- 非表示タグ：チップとカードの表示のみ変更。選択中なら「すべて」に戻す。
- 保存済み記事：取得元の無効化では削除しない。
- 表示順：未知・重複項目を除去し、新規項目を末尾に補完。

## 翻訳

- 対象：Android Developers のタイトルと概要（最大500文字）。
- 方式：ML Kit による英語→日本語の端末内翻訳。
- モデル未取得時：確認ダイアログの了承後にダウンロード。設定画面からの事前取得にも対応。
- 表示：翻訳後は原文／日本語訳を一つのボタンで切り替え。
- 保持：訳文は ViewModel 存続中のみ。モデルは端末に保持。
- 帰属：訳文に隣接して公式バッジ、設定画面に免責表示。

## 画面

- ヘッダー：ニュース／保存済み切り替え、更新、設定。
- 絞り込み：取得元・タグの2段。下スクロールで折りたたみ、上スクロールで再表示。
- 取得元・タグ・保存済み切り替え時：先頭へ戻り、絞り込み欄を再表示。
- 設定画面との往復時：選択・スクロール位置・折りたたみ状態を保持。無効になった選択は「すべて」に戻す。

## 通信・データの制約

- HTTPS、接続／読込タイムアウト各15秒、フィード上限2,000,000バイト。
- 自動リダイレクトなし。DOCTYPE を含むフィードは拒否。
- 記事 URL はユーザー情報を含まない http／https の絶対 URL に限定。
- URL で重複除去。概要の HTML タグは簡易除去。
- カスタム配信元はRSS／AtomフィードURLの直接入力に対応。WebサイトHTMLからのフィード自動検出、HTTP、認証付きURLは未対応。
- 本文取得・全文保存・未保存記事のディスクキャッシュ・定期更新・ログイン・端末間同期は対象外。
- 公開前に各配信元の利用条件・表示方法を再確認。
